# Smart Manufacturing Analytics & Predictive Maintenance Platform

## Overview
A full-stack predictive maintenance system for manufacturing environments using machine learning.

## Project Status
🔨 In Development (July 2026)

## Features
- Real-time sensor data visualization
- ML-powered equipment failure prediction
- RESTful API for maintenance teams
- Professional dashboard interface

## Technology Stack
- **Backend:** Python, Flask, Pandas, scikit-learn
- **Frontend:** React, Plotly
- **Database:** SQLite
